# Цифровой подарок ✨

Премиальный сайт-подарок в эстетике Apple: тёмная сцена, стеклянные элементы,
3D-коробка, письмо с эффектом печатной машинки, галерея воспоминаний
и кинематографичная презентация подарка.

## Быстрый старт

```bash
npm install
npm run dev
```

Открой http://localhost:5173

Сборка для публикации:

```bash
npm run build
```

Готовый сайт лежит в папке `dist` — её можно бесплатно выложить на
Vercel, Netlify или GitHub Pages.

## Как персонализировать

**Все тексты и подписи** — в одном файле: `src/data.js`.
Там же меняются заголовки, письмо, подпись кнопок и финальный экран.

**Фотографии** — положи свои снимки в `public/photos/`
и укажи их имена в `src/data.js` (поле `photos[].src`).

**Изображение подарка** — замени `public/gift.jpg` на фото своего подарка
(лучше горизонтальное, минимум 1600px по ширине).

**Скорость «печатной машинки»** — в `src/components/LetterSection.jsx`,
параметр `speed` (мс на символ).

## Структура

```
src/
  App.jsx                  — сценарий сайта (порядок экранов)
  data.js                  — все тексты и настройки контента
  components/
    IntroScreen.jsx        — первый экран с 3D-коробкой
    GiftBox.jsx            — 3D-коробка, частицы, свечение
    LetterSection.jsx      — письмо с эффектом печатной машинки
    GallerySection.jsx     — галерея с лайтбоксом
    GiftSection.jsx        — кинематографичная презентация подарка
    FinalSection.jsx       — финальный экран и кнопка «Посмотреть ещё раз»
    AmbientBackground.jsx  — живой градиентный фон
    ScrollProgress.jsx     — тонкий индикатор прокрутки
    Typewriter.jsx         — эффект печатной машинки
public/
  photos/                  — фотографии для галереи
  gift.jpg                 — изображение подарка
```

Технологии: React 18, Vite, Tailwind CSS 3, Framer Motion 11.
